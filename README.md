# 合禧请帖｜纯静态双页婚礼 H5

这是一个专为 GitHub Pages 设计的无服务器婚礼请帖制作器。填写新人姓名、日期、时间和地点后，会生成一条可分享的专属短链接；来宾打开链接后始终先看到欢迎封面，再进入婚礼详情页。

线上地址：<https://markjinli.github.io/hx/>

## 功能

- 4 个原创通用分享小图与 4 条通用分享文案可选
- 16 种组合固定使用 `a/` 至 `p/` 单字母入口
- 新请帖使用紧凑的 `#2.` 链接，同时继续识别旧版 `#i=v1.` 链接
- 自托管原创纯音乐、循环播放、移动端手势重试与暂停/恢复开关
- 专属链接打开两页 H5：欢迎封面、婚礼详情
- 系统分享、复制链接和微信降级提示
- 刷新或转发后始终从欢迎封面开始
- 损坏、截断和未知版本链接显示明确错误页
- 纯 HTML/CSS/JavaScript，无服务器、数据库、Cookie、统计脚本或外部字体

## 短链接

新链接格式：

```text
https://markjinli.github.io/hx/{a-p}/#2.<紧凑数据>.<CRC32>
```

单字母路径只表示所选图标与通用文案。姓名、日期、地点和寄语只存在 URL Fragment 中，不随网页请求发送给 GitHub。CRC32 仅用于发现链接截断或误改，不提供加密或防篡改能力；拥有完整链接的人仍可读取请帖内容。

旧版 `/#i=v1...` 与 `/share/v2/{图标}/{文案}/#i=v1...` 由旧仓库的兼容页转到新地址并保留 Fragment。

## 背景音乐

`m.mp3` 是项目自托管的原创婚礼纯音乐，约 3 分 13 秒、80 kbps、1.93 MB。页面会尝试播放；若微信或浏览器禁止有声自动播放，点击“开启请帖”会再次尝试。来宾也可使用请帖右上角按钮暂停或恢复。

## 本地预览与检查

```powershell
python -m http.server 4173
npm run check
```

`npm run build` 会根据根目录 `index.html` 重新生成 `a/index.html` 至 `p/index.html`。修改模板后须重新构建并提交生成页。

## 发布

仓库根目录就是发布目录，并包含 `.nojekyll`。GitHub Pages 从 `main` 分支的 `/ (root)` 发布，不依赖 GitHub Actions。微信可能缓存已分享链接的卡片，最终显示和音乐播放仍需在真实 iPhone/安卓微信中验收。

继续开发前请先阅读 `HANDOFF.md`。
